# Suhyeon Lee - Academic Portfolio

Welcome to my academic portfolio website! This site showcases my research, projects, and academic journey as an M.S. student at KAIST studying Digital Marketing and AI.

## 🌟 Features

- **Responsive Design**: Works perfectly on all devices
- **Modern UI**: Clean, professional academic portfolio design
- **Research Focus**: Highlighting publications, projects, and collaborations
- **Interactive Elements**: Smooth animations and user-friendly navigation
